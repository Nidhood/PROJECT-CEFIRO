# CEFIRO GUI v1.6

Dual simulation and /real telemetry overlays, pressure/magnetometer/DShot plots, history preservation and toggled command routing. Plant switch is disabled while output is enabled. DShot is host-requested code, not measured ESC data. Run hardware node in /real namespace. Requires ROS 2 Jazzy and cefiro_msgs. Not compiled or hardware-tested in this environment.
